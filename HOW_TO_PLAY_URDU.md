image.png# Fortuner City MVP — kaise chalayein

## Setup
1. Unity Hub install karo (winget / unity.com).
2. Unity **6** (6000.x) Editor install karo + **Windows Build Support**.
3. Hub → Open → `d:\office-work\fortuner-city-mvp`
4. Scene `Assets/Scenes/CityDrive` open karo → **Play**.

## Game
- Tum **Fortis XR** SUV drive karte ho (Fortuner-style).
- Poori chhoti city procedural generate hoti hai (roads, buildings, lamps).
- Roads pe ~12 NPC cars chal rahi hoti hain.

## Controls
- **W/S** — gas / brake-reverse  
- **A/D** — steer  
- **Space** — handbrake  
- **C** — camera chase/hood  
- **Esc** — pause · **R** — restart  

## Windows .exe
Unity ke andar: **Fortuner City → Build Windows Standalone**  
ya `build-windows.bat` run karo.
